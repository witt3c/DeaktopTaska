一、 隱私權政策 (Privacy Policy)

DesktopTaska 是一款注重個人與商業數據隱私的桌面代辦事項工具：

  • 完全本地化儲存： 您所建立的所有待辦事項、工程備註、客戶標籤與日期記錄，均完整儲存於您的個人電腦本地端（如 JSON 檔案），本軟體不會傳輸任何商業機密或代辦內容至外部雲端伺服器。
  • 無個人資料收集： 本軟體不要求註冊帳號，亦不收集您的姓名、電子郵件、IP 位址或任何識別性資訊。
  • 自動檢查更新： 軟體啟動時僅會讀取 GitHub 公開之版本號碼檔（version.json）以判斷是否有新版本提供下載，此過程不包含任何使用者個人數據。
